# 🎨 Раскрась мечту

Сайт, который помогает накопить деньги на желаемую цель и видеть свой прогресс.
Вместо обычной полоски — **большая картинка мечты**: сначала она бледная, а с каждым пополнением
наполняется цветом снизу вверх. Накопил 45% — раскрашено 45% картинки.

```
📱 Новый телефон
Цель: 120 000 ₽ · Накоплено: 54 000 ₽ · Осталось: 66 000 ₽
Картинка телефона раскрашена на 45%
```

## Возможности

- **Картинка мечты, которая наполняется цветом.** 21 встроенная картинка (телефон, ноутбук, наушники,
  машина, путешествие, дом…) или **своё фото** — например, того самого телефона. Пунктирная линия показывает текущий уровень,
  при пополнении заливка плавно дорастает, при 100% — конфетти.
- **Несколько мечт одновременно** — в списке у каждой своя мини-картинка с заливкой и процент.
- **Добавление накоплений** с датой и комментарием, быстрые кнопки +500 / +1 000 / +5 000 / +10 000.
- **Автоматический расчёт** накопленной суммы, остатка и процента выполнения.
- **История пополнений** (новые сверху), ошибочную запись можно удалить.
- **«Когда я накоплю?»** — указываешь, сколько можешь откладывать в месяц, сайт считает срок и примерную дату.
- **Сохранение данных** в браузере (`localStorage`) — после перезагрузки ничего не теряется.
  Своё фото уменьшается до 560 px, чтобы поместиться в память браузера.
- Кнопка **«Заполнить примером»** — для демонстрации на защите.
- Адаптивная вёрстка (телефон / планшет / ПК), нежно-зелёная палитра.

## Как запустить

Сайт статический — сборка не нужна.

- Просто открыть `index.html` в браузере, **или**
- запустить локальный сервер: `python3 -m http.server 8080` и открыть <http://localhost:8080>.

## Тесты

Расчёты вынесены в `js/calc.js` и покрыты тестами (нужен Node.js 18+):

```bash
npm test
```

Проверяется: пример из ТЗ (74 000 + 5 000 → 79 000 ₽, остаток 121 000 ₽, 39,5%), остаток не уходит в минус,
процент не больше 100 (и 100% — только когда цель реально достигнута), копейки считаются без ошибок, парсинг сумм,
прогноз (60 000 ₽ при 10 000 ₽/мес → 6 месяцев), склонения («1 месяц», «3 месяца», «2 года 2 месяца»),
форматирование дат и денег, наличие файла для каждой картинки мечты.

## Структура

```

css/style.css     — стили (нежно-зелёная тема, заливка картинки)

js/app.js         — интерфейс, события, хранение данных
img/dreams/       — SVG-картинки мечты
tests/            — тесты (node:test)
```

## Как устроена заливка картинки

Картинка выводится двумя одинаковыми слоями. Нижний — бледный (`filter: grayscale(1) opacity(.3)`),
верхний — цветной и обрезан через `clip-path: inset(<100 − процент>% 0 0 0)`, то есть виден только снизу
на высоту, равную проценту накоплений. SVG обрезаны по контуру рисунка, поэтому 0% — это низ самой
картинки, а 100% — её верх.

## Паспорт проекта

**1. Идея.** Сайт «Раскрась мечту», который помогает накопить на желаемую цель и видеть свой прогресс:
картинка мечты наполняется цветом по мере накоплений.

**2. Проблема.** Людям сложно регулярно откладывать деньги и отслеживать, сколько накоплено и сколько осталось.
Когда прогресс не виден, мотивация копить снижается.

**3. Цель.** Разработать простой и понятный сайт для контроля накоплений и отслеживания прогресса финансовой цели.

**4. Задачи.**
1. Продумать структуру и дизайн сайта.
2. Создать возможность добавлять финансовую цель.
3. Реализовать добавление накоплений.
4. Реализовать автоматический расчёт оставшейся суммы и процента выполнения.
5. Создать визуальное отображение прогресса — картинку мечты, которая наполняется цветом.
6. Реализовать историю пополнений.
7. Протестировать работу сайта.

**5. План.** Проектирование → Дизайн → Разработка → Тестирование → Презентация.

**6. Реализация.** Пользователь создаёт мечту и выбирает её картинку (или загружает своё фото), нажимает
«+ Добавить накопление», вводит сумму — сайт пересчитывает накопленное, остаток и процент, раскрашивает
соответствующую часть картинки, добавляет запись в историю и обновляет прогноз
«Когда я накоплю?»: `месяцев = ⌈остаток / взнос в месяц⌉`.

**7. Контроль.** Корректно ли добавляются накопления → правильно ли считается процент → правильно ли считается
остаток → сохраняются ли данные → удобно ли пользоваться сайтом.

**8. Результат.** Готовый веб-сайт, позволяющий создавать финансовые цели, добавлять накопления и наглядно
отслеживать прогресс их достижения по раскрашивающейся картинке мечты.

> Сознательно **не** входит в проект: банки, реальные платежи, карты, курсы валют, ИИ.
