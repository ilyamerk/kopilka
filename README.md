# MONETA.

**Твои деньги. Твои цели. Твой контроль.**

Личные финансы в одном веб-приложении (PWA — сайт, который ставится на экран «Домой» и работает как приложение, в том числе без интернета). Внутри три раздела:

- **Финансы** — расходы и доходы, а переключателем сверху — долги;
- **Аналитика** — месяц в цифрах и графиках, выгрузка для ИИ и в Excel;
- **Накопления** — копилки на мечту с прогрессом и прогнозом «Когда я накоплю?».

MONETA объединяет два проекта: [«Трекер расходов»](https://github.com/ilyamerk/trecker_rashody) и «Копилку на мечту» (её первая версия — в истории этого репозитория).

- **Без сервера и бесплатно.** Код лежит на GitHub Pages, данные хранятся на устройстве.
- **«База данных» — второй, приватный репозиторий.** Приложение хранит там файл `data.json` и синхронизирует его между телефоном и компьютером. История коммитов заодно служит бэкапом.
- **Рубли, суммы с копейками.** Светлая и тёмная тема подстраиваются под систему.

## Что умеет

### Финансы
- **Расходы и доходы**: сумма, категория, дата, комментарий. Правка, удаление с кнопкой «Вернуть».
- **Категории**: 15 базовых для расходов и 5 для доходов, свои — прямо из формы операции.
- **Регулярные платежи**: подписки, аренда, зарплата — раз в месяц или раз в год, записываются сами (🔁), без дублей.
- **Быстрые кнопки**: «☕ Кофе 250 ₽» — запись в одно касание.
- **Долги**: «мне должны» и «я должен», срок возврата, частичные возвраты, просроченные — с красной точкой, кнопка «Напомнить».

### Аналитика
- Расходы, доходы и остаток за месяц, сравнение с прошлым месяцем, средний расход в день, категории, график по дням, последние 6 месяцев, самые крупные траты.
- **Сколько отложено в копилки** за месяц и какая это доля дохода.
- **Выгрузка для ИИ** (`.md`) — с заданием для нейросети, сводкой, всеми операциями и **разделом про копилки** (успеваешь ли к целям). **Выгрузка в Excel/CSV.**

### Накопления (копилки)
- **Несколько копилок**: эмодзи, название, стоимость цели, «уже накоплено» при создании.
- **Пополнение** с датой и комментарием, быстрые кнопки **+500 / +1 000 / +5 000 / +10 000**. Дата в будущем запрещена.
- **Автоматический расчёт** накопленного, остатка и процента (до десятых: 79 000 из 200 000 → 39,5 %), прогресс-бар, общая сводка.
- **История пополнений** (свежие сверху), ошибочную запись можно удалить и вернуть.
- **«Когда я накоплю?»**: указываешь, сколько можешь откладывать в месяц, — срок и примерный месяц пересчитываются на лету: `месяцев = ⌈остаток / взнос в месяц⌉`.
- **Конфетти 🎉**, когда цель достигнута. Кнопка **«Заполнить примером»** — для демонстрации.
- Копилки **не смешиваются с расходами**: это отложенные деньги, а не потраченные. Синхронизируются вместе со всем остальным.

### Общее
- **PIN-код и Face ID / Touch ID**, размытие экрана в переключателе приложений.
- **Резервная копия** в JSON и восстановление из неё.

## Переезд со старых приложений

Если «Трекер расходов» или «Копилка на мечту» открывались в этом же браузере с того же адреса (`<логин>.github.io`), при первом запуске MONETA **сама скопирует** их данные: операции, категории, долги, регулярные платежи, настройки (PIN, синхронизацию) и копилки. Старые данные не изменяются.

> ⚠️ **После переезда пользуйся только MONETA.** Формат данных стал версией 2 (добавились копилки). Старый трекер, подключённый к тому же репозиторию с данными, увидит ошибку «Файл от более новой версии приложения» и ничего не запишет — это защита, чтобы он не стёр копилки. Если синхронизация в старом трекере была включена, в MONETA она уже подключена — ничего вводить не нужно.

## 1. Публикация на GitHub Pages (один раз)

1. Репозиторий должен быть **публичным** (на бесплатном тарифе Pages работает только так). Публичным становится только код: твои траты сюда не попадают.
2. **Settings → Pages → Source: GitHub Actions.**
3. Влей изменения в `main` (или **Actions → Tests & Deploy → Run workflow**) и дождись зелёной галочки.
4. Сайт появится по адресу `https://<логин>.github.io/kopilka/`.

Если деплой упал на шаге `configure-pages`, значит не выполнен пункт 2.

## 2. Установка на айфон

1. Открой ссылку **в Safari**.
2. «Поделиться» → **«На экран „Домой“»** → «Добавить».
3. Запускай MONETA с иконки.

> ⚠️ У Safari и у приложения с экрана «Домой» **разные хранилища**. Данные из Safari не появятся в установленном приложении, пока не включена синхронизация.

## 3. Синхронизация через приватный репозиторий

1. Создай **приватный** репозиторий, например `moneta-data` (или используй тот, что был у трекера): <https://github.com/new> → **Private**, отметь **Add a README file**.
2. Создай fine-grained токен: <https://github.com/settings/personal-access-tokens/new> → Repository access: **Only select repositories** → этот репозиторий; Permissions → Repository → **Contents: Read and write**; Expiration — на год вперёд.
3. **Настройки → Синхронизация через GitHub** → `логин/moneta-data` и токен → «Подключить».
4. Второе устройство — по QR-коду: «Подключить другое устройство» → «Показать QR-код» и «📷 Сканировать QR-код» на втором.

> ⚠️ В QR-коде и ключе — токен. Не делай скриншот и не пересылай ключ в чаты.

**Как работает.** При открытии, через ~1,5 с после правки и раз в минуту устройство читает `data.json`, сливает со своими данными и при необходимости записывает обратно. Побеждает более свежая правка, удаление хранится «надгробием» и не воскресает. Публичный репозиторий приложение не примет.

## 4. PIN-код и Face ID

**Настройки → Защита → Поставить PIN-код.** Хранится только хэш PIN (PBKDF2 с солью). После 5 неверных попыток — пауза, она растёт до часа. «Забыли PIN?» стирает данные этого устройства (с синхронизацией они вернутся). Это защита от человека с твоим разблокированным телефоном, а не шифрование.

## Разработка

```bash
npm start   # http://localhost:8080 (без офлайн-кэша, правки видны сразу)
npm test    # тесты логики, копилок, синхронизации, PIN, QR, целостности файлов
```

Сборки и зависимостей нет: чистые HTML/CSS/JS-модули, нужен Node.js 18+ только для тестов.

## Паспорт проекта

**1. Идея.** MONETA — веб-приложение, где в одном месте видно, куда уходят деньги и сколько накоплено на мечту.

**2. Проблема.** Людям сложно регулярно откладывать деньги и отслеживать, сколько накоплено и сколько осталось. Когда не видно, куда уходят деньги и как растут накопления, мотивация копить снижается.

**3. Цель.** Разработать простой и понятный сайт для учёта расходов и доходов, контроля накоплений и отслеживания прогресса финансовых целей.

**4. Задачи.**
1. Продумать структуру и дизайн: три раздела — Финансы, Аналитика, Накопления.
2. Реализовать учёт расходов, доходов и долгов.
3. Создать возможность добавлять финансовую цель и пополнять её.
4. Реализовать автоматический расчёт остатка, процента выполнения и прогноза.
5. Создать визуальное отображение прогресса и аналитику.
6. Реализовать историю пополнений и сохранение данных.
7. Протестировать работу сайта.

**5. План.** Проектирование → Дизайн → Разработка → Тестирование → Презентация.

**6. Реализация.** Пользователь записывает траты и доходы, создаёт мечту и нажимает «＋ В копилку» — приложение пересчитывает накопленное, остаток и процент, добавляет запись в историю и обновляет прогноз «Когда я накоплю?». В аналитике видно, сколько отложено за месяц.

**7. Контроль.** Автотесты (`npm test`): пример из ТЗ (74 000 + 5 000 → 79 000 ₽, остаток 121 000 ₽, 39,5 %), остаток не уходит в минус, процент не больше 100, копейки без ошибок, прогноз (60 000 ₽ при 10 000 ₽/мес → 6 месяцев), склонения, синхронизация копилок, перенос данных.

**8. Результат.** Готовое приложение, которое позволяет вести бюджет, ставить финансовые цели, пополнять копилки и наглядно отслеживать прогресс.

## Ограничения

- Одна валюта — рубли.
- Синхронизация не мгновенная: изменения с другого устройства приходят в течение минуты.
- Регулярные платежи записываются, только когда приложение открыто.
